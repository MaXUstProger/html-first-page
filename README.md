# HTML First Page

Мой первый учебный проект в рамках курса по веб-разработке.

Проект создан для изучения основ HTML и структуры веб-страниц.

## О проекте

Это простая HTML-страница, созданная без использования сторонних библиотек и фреймворков.

В процессе разработки были изучены:

- структура HTML-документа;
- основные HTML-теги;
- работа с текстом;
- создание ссылок;
- добавление изображений;
- базовая организация файлов проекта.

## Используемые технологии

- HTML5

## Запуск проекта

Проект не требует установки зависимостей.

Для запуска:

1. Скачайте репозиторий.
2. Откройте файл:
index.html

в браузере.
